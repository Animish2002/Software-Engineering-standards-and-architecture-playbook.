# Hono project structure

```text
apps/worker/
├── wrangler.jsonc          (or wrangler.toml)
├── package.json
├── tsconfig.json
├── worker-configuration.d.ts   generated by `wrangler types` (Env bindings)
├── .dev.vars                   local secrets (git-ignored)
└── src/
    ├── index.ts                export default app (fetch), plus scheduled/queue handlers if any
    ├── app.ts                  createApp(): middleware + routes
    ├── env.ts                  Env type + Zod validation of vars
    ├── modules/
    │   ├── auth/
    │   │   ├── auth.routes.ts      Hono sub-app
    │   │   ├── auth.service.ts
    │   │   └── index.ts
    │   ├── items/
    │   └── shares/
    ├── middleware/             authenticate.ts, require-permission.ts, request-context.ts
    ├── lib/                    errors.ts, response.ts, jwt.ts, logger.ts
    └── db/                     drizzle client factory (per-request on Workers)
```

## `index.ts`

```ts
import { createApp } from './app';
import type { Env } from './env';

const app = createApp();

export default {
  fetch: app.fetch,
  // scheduled: async (event, env, ctx) => { ... },        // Cron Triggers
  // queue: async (batch, env, ctx) => { ... },             // Queues consumer
} satisfies ExportedHandler<Env>;
```

## `app.ts`

```ts
import { Hono } from 'hono';
import { cors } from 'hono/cors';
import { secureHeaders } from 'hono/secure-headers';
import { requestId } from 'hono/request-id';
import type { AppEnv } from './env';
import { requestContext } from './middleware/request-context';
import { errorHandler, notFound } from './lib/errors';
import { authRoutes } from './modules/auth';
import { itemsRoutes } from './modules/items';
import { sharesRoutes } from './modules/shares';

export function createApp() {
  const app = new Hono<AppEnv>();

  app.use('*', requestId());
  app.use('*', requestContext);
  app.use('*', secureHeaders());
  app.use('/api/*', cors({ origin: (origin, c) => (origin === c.env.CORS_ORIGIN ? origin : ''), credentials: true, exposeHeaders: ['X-Request-Id'] }));

  app.get('/health', (c) => c.json({ success: true, data: { status: 'ok' } }));

  app.route('/api/auth', authRoutes);
  app.route('/api/shares', sharesRoutes);
  app.route('/api', itemsRoutes);          // spans /items, /folders, /files

  app.notFound(notFound);
  app.onError(errorHandler);
  return app;
}
```

`app.route(prefix, subApp)` is the Hono equivalent of Express's prefixed
mounting; the same shadowing hazard applies if a sub-app applies
`use('*', authenticate)` and is mounted without a prefix. Always mount
with prefixes; register public routes before auth middleware within a
sub-app.

## Typed environment

```ts
// env.ts
export type Env = {
  DB: Hyperdrive;             // or D1Database, or a plain DATABASE_URL string
  FILES: R2Bucket;
  CACHE: KVNamespace;
  JOBS: Queue<JobMessage>;
  JWT_SECRET: string;
  CORS_ORIGIN: string;
};
export type Variables = { reqId: string; user?: AuthUser; log: Logger };
export type AppEnv = { Bindings: Env; Variables: Variables };
```

Every `new Hono<AppEnv>()` gets typed `c.env` and `c.get('user')`.

## Node target

Same structure; replace `index.ts` with:

```ts
import { serve } from '@hono/node-server';
serve({ fetch: app.fetch, port: config.PORT });
```

and use a normal pooled Drizzle client ([database-access.md](database-access.md)).
