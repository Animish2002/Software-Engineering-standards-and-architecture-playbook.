# shadcn component organization

```text
components/
├── ui/          generated by `npx shadcn add`; primitives only; edited minimally
└── common/      app-level components built ON ui/: ConfirmDialog, FormDialog, PageHeader, EmptyState, DataTable parts, RowMenu, SearchInput, MultiSelect
```

## `ui/`

- Add components with the CLI; don't hand-write primitives that shadcn provides.
- Keep file names as generated (`button.tsx`, `dropdown-menu.tsx`).
- Edits allowed: token/colour tweaks, added `cva` variants, small accessibility fixes, forwarding an extra prop. Not allowed: business logic, data fetching, app-specific props (`user`, `onTrash`).
- When shadcn updates a component, re-add it and diff; small edits merge easily, rewrites don't.
- Don't export a "barrel" from `ui/`; import from the file (`@/components/ui/button`) so tree-shaking and grep stay clear.

## `common/`

- Composes `ui/` parts into app-level units with a small prop surface ([../10-frontend/components/catalog.md](../10-frontend/components/catalog.md)).
- No feature knowledge. `ConfirmDialog` doesn't know what it confirms.
- Each file one component (plus compound parts).

## What to add, and when

| Need | Add |
| --- | --- |
| Actions | `button` |
| Modal flows | `dialog`, `alert-dialog` (destructive confirmations), `sheet` (mobile side panels) |
| Menus | `dropdown-menu` (row actions), `context-menu` (right-click on cards) |
| Forms | `form`, `input`, `textarea`, `label`, `select`, `checkbox`, `switch`, `radio-group` |
| Pickers | `popover` + `command` (combobox, multi-select), `calendar` if dates |
| Data | `table`, `badge`, `skeleton`, `tooltip`, `avatar`, `progress` |
| Navigation | `tabs`, `breadcrumb`, `sidebar` (the shadcn sidebar block is a good base), `navigation-menu` rarely |
| Feedback | `sonner` (toasts), `alert` (inline notices) |
| Command palette | `command` + `dialog` |

Don't add everything upfront; add on first real need. Delete unused ones.

## Blocks

shadcn "blocks" (dashboard, sidebar, login) are good starting points for
layouts; copy, then trim to what the app needs rather than keeping the
whole block.
